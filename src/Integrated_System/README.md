# Integrated System

This folder contains the integrated implementation of the VISTRA Smart Hat.

The system combines:

- Whisper / whisper.cpp for real-time speech transcription
- YAMNet for hazardous environmental sound recognition
- Direction of Arrival (DoA) estimation using the ReSpeaker microphone array
- SSD1322 OLED display for subtitles and warning messages
- LED indicators for sound-source direction
- Raspberry Pi-based edge processing

The integrated system is designed to convert important auditory information into visual information for hearing-impaired users.
